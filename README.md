# PlayGuide
一款内嵌网页工具，用于在全屏游戏上置顶播放游戏攻略视频，并实现对视频进行控制，支持快捷键播放启停、快进、快退。以及实现窗口控制功能，支持快捷键隐藏、显示、窗口透明度控制，按键生效控制等操作
# 功能
1. 控制窗口自动隐藏、边缘吸附，主窗口获取鼠标焦点时显示；
2. 设置页可以自定义快捷键、按键捕获方式、主页设置、以及主题、开机、性能等选项；
3. 状态恢复功能：会恢复上次关闭关键时的状态
4. 主窗口自动吸附
